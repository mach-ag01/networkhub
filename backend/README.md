# NetworkHub API
Django REST Framework backend. Routes: `/health/`, `/api/v1/auth/register/`, `/api/v1/auth/login/`, `/api/v1/auth/refresh/`, `/api/v1/auth/me/`, `/api/v1/products/`, `/api/v1/services/`, `/api/v1/favorites/`, `/api/v1/enquiries/`, `/api/v1/analytics/events/`, `/api/v1/admin/overview/`. Use `Authorization: Bearer <access-token>`.
